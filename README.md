## 🧩 核心方法論

這個生態系裡的所有內容，都建立在同一組底層框架上：

- **渴望行銷**：從客戶自己說出口的語言出發，寫他們渴望的樣子，而不是戳他們的痛
- **LIFE 根系內容系統**：讓一支內容長出整週的素材，而不是每天從零開始想
- **IG ＋ Skool 變現模型**：Instagram 負責被看見，Skool 負責被信任跟被付費
- **神經系統安全感**：能長期執行的系統，建立在穩定的身心狀態上
- **三大內容支柱**：系統｜豐盛與身份｜自由生活

所有框架皆屬於奇蹟研究所知識體系。

## 🤖 我實際在用的 AI 工作流

不是拿 AI 拚產量，是拿 AI 換回時間。

| 工具 | 用途 |
| --- | --- |
| **Claude** | 內容主引擎。品牌大腦、逐字稿改寫、貼文與信件生產 |
| **Claude Code** | 自動剪片、批次處理、把工作流寫成可重複執行的程式 |
| **Claude Skills** | 把每一種內容格式包成可安裝的 `.skill`：短影音腳本、養成信、輪播、社群貼文、內容瀑布流 |
| **MCP 串接** | 讓 Claude 直接讀寫 Notion 內容日曆、Google Drive 素材庫 |
| **ManyChat** | Instagram 自動私訊導流與成交 |
| **客製 GPT** | 特定情境的輕量助手，例如富命特助 |

工具會換，底層邏輯不會：先把流程想清楚，再讓 AI 執行。
